How it's built

The puzzle logic is plain TypeScript with unit tests, and the view only animates what a move returns. Blocks sit on damped springs integrated with fixed substeps, so the jelly moves the same at 20 and 120 fps. GSAP, springs and screen shake all run on one game clock, which makes hit-stop and pausing the ad a single call.

Every network build contains only its own API, and a preflight script fails the build on external resources or a missing API. Graphics are drawn in code and sound is synthesized, so the build has no image or audio files. It becomes interactive in about 0.7 s with the CPU throttled four times, and profiling cut garbage by 40%. Open the playable with ?debug for live frame times on your own device.
